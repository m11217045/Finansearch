# Agent 分析師設定資料夾

此資料夾包含了所有分析師的提示詞和設定檔案，讓使用者能夠自定義和擴展多代理人分析系統。

## 檔案說明

### 核心分析師
1. **buffett_value_investor.txt** - 巴菲特派價值投資師
   - 專注於護城河評估、管理層品質、財務分析
   - 強調長期價值投資原則

2. **munger_multidisciplinary_analyst.txt** - 芒格多學科分析師
   - 運用心理學、統計學、經濟學等多學科方法
   - 識別認知偏誤和系統性風險

3. **growth_value_investor.txt** - 成長價值投資師
   - 平衡成長潛力和價值評估
   - 關注PEG比率和成長品質

4. **market_timing_analyst.txt** - 市場時機分析師
   - 結合技術分析和市場週期判斷
   - 關注進出場時機

5. **risk_management_expert.txt** - 風險管理專家
   - 專注於風險識別、量化和管理
   - 提供投資組合風險控制建議

### 擴展分析師
6. **esg_sustainability_expert.txt** - ESG永續投資專家
   - 評估環境、社會、治理因素
   - 關注永續發展和社會責任

7. **quantitative_investment_analyst.txt** - 量化投資分析師
   - 使用數據建模和統計分析
   - 提供量化指標和因子評分

8. **technology_industry_expert.txt** - 科技產業專家
   - 專注科技趨勢和創新評估
   - 分析技術護城河和數位轉型

9. **macroeconomic_analyst.txt** - 總體經濟分析師
   - 從宏觀經濟角度評估投資機會
   - 關注貨幣政策和經濟週期

10. **behavioral_finance_expert.txt** - 行為金融專家
    - 分析市場情緒和投資者行為
    - 識別認知偏誤和非理性現象

## 自定義方法

### 修改現有分析師
1. 開啟對應的 .txt 檔案
2. 修改分析框架或提示詞
3. 調整輸出格式的欄位
4. 儲存檔案後重新啟動系統

### 新增自定義分析師
1. 建立新的 .txt 檔案
2. 按照以下格式設計：
   ```
   # 分析師名稱
   # 角色：角色描述
   # 專長：專長領域
   # 投資風格：投資風格描述

   ## 分析框架
   [分析框架內容]

   ## 初始分析任務
   [初始分析提示詞]

   ## 辯論分析任務
   [辯論分析提示詞]

   ## 輸出格式
   [JSON輸出格式]
   ```

3. 在程式碼中註冊新的分析師

## 使用建議

1. **選擇適當的分析師組合**：根據分析需求選擇合適的分析師團隊
2. **平衡觀點**：確保分析師組合涵蓋不同投資哲學
3. **自定義調整**：根據市場環境調整分析師的權重和設定
4. **持續優化**：定期檢視和優化分析師的表現

## 技術整合

這些 txt 檔案可以：
- 直接在程式碼中讀取和解析
- 動態載入不同的分析師設定
- 支援熱更新和即時調整
- 方便版本控制和團隊協作

## 注意事項

- 修改提示詞時請保持 JSON 輸出格式的一致性
- 分析框架應涵蓋該分析師的核心專長
- 確保提示詞的語言清晰且專業
- 定期更新以反映市場變化
